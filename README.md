## 介绍

RainWright 是面向《Rain World》区域创作者的可视化编辑器 Mod。它重新设计了游戏开发工具的界面，将房间、物件、世界连接、生物生成、地图和声音编辑集中在同一个工作区，方便制作和调整自定义区域。

## 依赖

- 《Rain World》及其游戏开发工具
- Rain World ImGUI API 1.12.0 或更新版本
- Rain World ImGUI API 所需的 Library Loader

在 Remix 中启用依赖和 RainWright，并开启游戏开发工具。RainWright 无需安装 DryCycle 或 Ancient Site。
